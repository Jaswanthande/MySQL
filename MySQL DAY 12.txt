SET OPERATORS
=============
UNION
-----
COMBINES RESULTS FROM TWO QUERIES AND REMOVE DUPLICATE ROWS.
COLUMNS MUST HAVE THE SAME NUMBER AND TYPE

UNION AL
--------
COMBINES RESULTS FROM TWO QUERIES AND INCLUDING DUPLICATE ROWS.
COLUMNS MUST HAVE THE SAME NUMBER AND TYPE

INTERSECT
---------
RETURNS ROWS THAT ARE COMMON TO BOTH QUERIES.COLUMNS MUST HAVE THE SAME NUMBER AND TYPE
NOTE: MYSQL DOSEN'T SUPPORT INTERSECT DIRECTLY.

MINUS
------
RETURNS ROWS FROM THE FIRST QUERY THAT ARE NOT PRESENT IN THE SECOND QUERY COLUMNS MUST HAVE THE SAME NUMBER AND TYPE.
NOTE: MYSQL DOSEN'T SUPPORT MINUS DIRECTLY.
