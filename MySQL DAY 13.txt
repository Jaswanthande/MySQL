NUMERIC FUNCTIONS 

Numeric functions are built-in functions used to perform mathematical calculations and manipulate numeric values.

FUNCTION			DESCRIPTION							     EXAMPLE			OUTPUT
ABS()			Returns the absolute (positive) value					SELECT ABS(-25);		25
CEIL() / CEILING()	Rounds a number up to the nearest integer				SELECT CEIL(12.3);		13
FLOOR()			Rounds a number down to the nearest integer				SELECT FLOOR(12.9);		12
ROUND()			Rounds a number to the nearest integer or specified decimal places	SELECT ROUND(12.56,1);		12.6
MOD()			Returns the remainder after division					SELECT MOD(10,3);		1
POWER() / POW()		Returns a number raised to a power					SELECT POWER(2,4);		16
