aggregate functions
===================
count
-----
count the number of records.
sum
---
returns the total sum of numeric column.
avg
---
returns the average value.
min
---
returns  the minimum value.
max
---
returns  the maximum value.

CLAUSES
=======
In MYSQL clauses are used to control how data is selected ,filtered, grouped, sorted, modified in MYSQL queries.

think of clauses like instructions given to the databases.
 
where clause
------------
filter records based on specified conditions where clause can be used as comparison operators, logical operators ..etc... operators.

syntax
------
select column1,column2.....
from table
where condition

group by clause
---------------
it is used to group rows having same values in one or more columns.it is commonly used with aggregate functions such as sum(), min(), max(), AVG(), count().

syntax
------
select column-name, aggregate function(column-name)
from table
group by column-name;

having clause
--------------
it is used to filter grouped records after group by clause.it is similar to where but it works on grouped instead of individual rows.

syntax
------
select column-name, aggregate-function(column-name)
from table
group by column-name;
having condition

order by
--------
it is used to sort the result set in ascending order (ASC) or descending order(DESC)
ASC--ascending order by default
DESC--descending order 

syntax
------
select column-name
from table-name
order by column-name;
